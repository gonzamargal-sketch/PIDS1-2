# Documentación

Todo lo escrito del proyecto vive en esta carpeta. El [`README.md`](../README.md)
de la raíz es solo la guía de arranque: cómo levantarlo y cómo se usa.

| Documento | Qué es | Cuándo se lee |
|---|---|---|
| [`ARQUITECTURA.md`](ARQUITECTURA.md) | El documento de diseño: alcance, decisiones cerradas y por qué cada una es la que es | **Primero.** Al menos §3.1, §3.2 y §3.3 antes de escribir una línea |
| [`REPARTO.md`](REPARTO.md) | Los cuatro bloques y de quién es cada uno | Al empezar, para saber qué te toca |
| [`TAREAS.md`](TAREAS.md) | Las 17 tareas pendientes, con dueño, ficheros propios y criterio de «hecho» | Cada vez que coges trabajo nuevo |

De las tres, `ARQUITECTURA.md` es la que manda: si el código y el documento no
coinciden, el que está mal es el código.

## Lo que se irá añadiendo

Estos aún no existen; los crean las tareas de cierre (T5.x de
[`TAREAS.md`](TAREAS.md)):

- `MEDICIONES.md` — las seis métricas de §7 medidas de verdad, con capturas.
- `memoria/` — un fichero por bloque, para poder escribir los cuatro a la vez.
- `GUION_VIDEO.md` — el guion de los 5-10 minutos.
